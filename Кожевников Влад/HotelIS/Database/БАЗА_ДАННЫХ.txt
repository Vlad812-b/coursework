БАЗА ДАННЫХ ПРОЕКТА «СОПРОВОЖДЕНИЕ ИС ГОСТИНИЧНОГО БИЗНЕСА»
================================================================

Тип СУБД: SQLite (встроенная, файловая)
Файл базы:  Hotel.db
MySQL:      НЕ используется — ничего скачивать и устанавливать не нужно

КАК СОЗДАЁТСЯ БАЗА
------------------
1. Запустите программу (F5 в Visual Studio).
2. При первом запуске автоматически:
   - создаётся папка Database рядом с HotelIS.exe;
   - выполняется скрипт CreateDatabase.sql;
   - заполняются демонстрационные данные (клиенты, номера, брони, пользователи).

Путь к файлу после сборки:
  HotelIS\bin\Debug\net8.0-windows\Database\Hotel.db

ДЕМО-ДАННЫЕ (как в вашей базе Access)
------------------------------------
  5 клиентов, 5 номеров, 6 бронирований — подставляются при первом
  запуске, если таблицы пустые.

  Если таблицы пустые в программе:
  1. Закройте HotelIS.
  2. Удалите файл Hotel.db (см. путь выше).
  3. Запустите F5 снова.

ТАБЛИЦЫ
-------
  Пользователи  — вход в систему (логин, пароль, роль)
  Клиенты       — гости отеля
  Номера        — номерной фонд
  Бронирование  — связь клиент + номер + даты + сумма

ПРОСМОТР БАЗЫ (по желанию)
--------------------------
Можно открыть Hotel.db в бесплатной программе «DB Browser for SQLite»
(не обязательно для работы приложения).

Скрипт создания таблиц: CreateDatabase.sql
Описание полей:         Схема_базы.txt
