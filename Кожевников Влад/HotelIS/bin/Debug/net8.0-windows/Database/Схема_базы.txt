СХЕМА БАЗЫ ДАННЫХ «ГОСТИНИЦА» (SQLite, файл Hotel.db)
=====================================================

ТАБЛИЦА: Пользователи
---------------------
Код         — INTEGER, ключ, автоувеличение
Логин       — TEXT, уникальный
Пароль      — TEXT (хэш SHA-256)
Роль        — TEXT (Admin / User)
Имя         — TEXT

ТАБЛИЦА: Клиенты
----------------
ID_Клиента  — INTEGER, ключ, автоувеличение
Фамилия     — TEXT
Имя         — TEXT
Телефон     — TEXT
Паспорт     — TEXT

ТАБЛИЦА: Номера
---------------
ID_Номера   — INTEGER, ключ, автоувеличение
Номер       — INTEGER
Категория   — TEXT
Цена        — REAL
Статус      — TEXT  (Свободный, Занят, На ремонте)

ТАБЛИЦА: Бронирование
---------------------
ID_Брони    — INTEGER, ключ, автоувеличение
ID_Клиента  — INTEGER → Клиенты
ID_Номера   — INTEGER → Номера
ДатаЗаезда  — TEXT (дата)
ДатаВыезда  — TEXT (дата)
Итог        — REAL

СВЯЗИ:
Клиенты (1) — (∞) Бронирование
Номера (1) — (∞) Бронирование

ДЕМОНСТРАЦИОННЫЕ ДАННЫЕ (как в Access)
-------------------------------------
Клиенты: 5 записей (Иванов … Смирнов)
Номера:  5 записей (Семейный … Эконом)
Бронирование: 6 записей

Скрипт заполнения: SeedData.sql

Если данные не отображаются — удалите файл Hotel.db и запустите
программу снова (F5). База создастся заново с демо-данными.

Просмотр базы: DB Browser for SQLite (по желанию).
